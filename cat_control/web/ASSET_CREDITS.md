# 3D asset credits

The bundled `assets/bicolor_cat.glb` is **Bicolor Cat** by kenchoo, based on
the original model by guillaume bolis. It is distributed under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

Source: https://sketchfab.com/3d-models/bicolor-cat-e623a618ca344a8393d7ba4d63ec23cf

The application uses the asset as a local, pre-bundled character model. The
procedural character remains as a fallback if the asset cannot be loaded.
